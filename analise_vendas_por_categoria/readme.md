
Projeto desenvolvido para praticar análise de dados utilizando SQL e Power BI a partir do dataset público da Olist.

## Objetivo

O objetivo deste projeto é identificar quais categorias de produtos possuem:

- Maior volume de vendas
- Maior faturamento
- Melhor desempenho geral dentro do marketplace

---

## Tecnologias Utilizadas

- SQLite
- SQL
- Power BI

---

## Análise SQL

A consulta foi desenvolvida utilizando:

- JOIN entre tabelas
- Agrupamento de dados
- Funções de agregação

Principais métricas utilizadas:

- Quantidade de itens vendidos
- Valor total de vendas por categoria

---

## Dashboard Power BI

O dashboard apresenta:

- Quantidade total de itens vendidos
- Valor total de vendas
- Ranking de categorias por volume
- Ranking de categorias por faturamento
- Filtro interativo por categoria

---

## Insight Principal

A categoria `beleza_saude` aparece entre as líderes tanto em quantidade de vendas quanto em faturamento, indicando forte relevância dentro do marketplace.

---

## Dataset

Dataset público da Olist disponibilizado no Kaggle.
